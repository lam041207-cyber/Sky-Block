# 🌍 Skyblock 3D

A browser-based 3D block-building sandbox where you can create, explore, and customize your own island world.

🎮 **Live Demo:** https://comfy-arithmetic-7f6613.netlify.app/

## ✨ Features

- 🧱 **3D Block World** – Build and customize your own environment.
- 🖱️ **Place Blocks** – Use left-click to place blocks.
- ⛏️ **Remove Blocks** – Use right-click to destroy blocks.
- 🎥 **Camera Controls** – Rotate and explore your world.
- 🔍 **Zoom System** – Zoom in and out to explore your island.
- 🎨 **Block Selection** – Choose different blocks using number keys.

## 🎮 Controls

| Control | Action |
|---|---|
| Left Click | Place block |
| Right Click | Remove block |
| Drag Mouse | Rotate camera |
| Scroll | Zoom in/out |
| 1–5 | Select block |

## 🎯 Project Vision

The goal of Skyblock 3D is to transform a simple block-placement game into a living island civilization.

Players will be able to explore a world where NPCs independently mine, build, farm and craft while weather and environmental conditions constantly change.

I want to create a cozy, interactive and immersive world that players can enjoy exploring and developing.
